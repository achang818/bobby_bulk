# Build complete Recommended Workouts

Fix generated sessions that stop after one priority exercise despite having no
time limit and other suitable work available. Use priorities to guide emphasis,
ordering, and set allocation within a complete session. Consider lower-priority
and unranked muscles even when a priority still needs attention. Treat weekly
frequency targets as guidance, not automatic exclusions.

Keep the existing four-movement session budget as a product heuristic. Aim for
multiple useful, nonredundant movements, without padding a workout or overriding
recent-work, high-workload, equipment, goal, or exclusion constraints. Preserve
direct/supporting stimulus accounting, exercise continuity, time adaptation,
load targets, and the boundary between generated workouts and user-owned plans.
Explain a short session visibly when constraints leave fewer than three suitable
movements. This is a construction heuristic, not a universal training minimum.

Reproduce the reported pattern using synthetic history: abs is the highest
priority with one exposure remaining, other priorities meet frequency guidance
or have high recent workload, and other suitable muscles remain available. An
unrestricted session must retain abs work and include useful additional work;
a tight time budget may still produce one movement. Verify met-frequency muscles
remain eligible, recovery guards also apply to broader selection, redundant work
isn't used as filler, and preview prescriptions survive start and resume.

Update the relevant master-spec guidance, run tests/build/lint, inspect the result
with the user's saved data read-only, and check desktop/mobile browser behavior.
